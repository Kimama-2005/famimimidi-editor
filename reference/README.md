# reference/ — claude.ai 上で使ったスクリプト

すべて Python 3 の標準ライブラリだけで SMF(.mid)を書き出す。出力先は `/tmp/fmm/` に固定されているので、使う場合は書き換えること。
**参考実装であって、本ソフトのコードではない。** MIDIファイルの組み立て方と、マクロ書き込みの送信順序の実例として使う。
検証には `mido`(pip)で読み戻していた。

共通の小関数: `vlq()`(可変長数値)、`cc()` / `pcm()` / `non()` / `nof()` / `pbm()`(メッセージ生成)、`mk()`(トラック組み立て、`(tick, bytes, 優先度)` のリストを時刻順にソートして差分時間に変換)、`build()`(ヘッダ+トラック)。

## 音色・曲

| ファイル | 内容 |
|---|---|
| `mk.py` | 疑似ギター2種(設定のみの .mid) |
| `follin.py` | Tim Follin 風の音色+21小節のデモ |
| `song.py` | 同、36小節のループ曲(ch5 DPCMドラム) |
| `song2.py` | ドラムを ch4 ノイズに置き換えた版(ヒット毎に CC#75 を打ち替え) |
| `song3.py` | キックを三角波 ch3 に移した版(ベースを退避させる処理あり) |
| `jpop.py` | J-POP リード3種+王道進行16小節のデモ(伴奏つき) |

## マクロ・書き込み

| ファイル | 内容 | 結果 |
|---|---|---|
| `macro.py` | 32CCマクロを PC89-91 へ / リセット無しインライン版 / 差分版 / PC切替デモ | 32CCは容量超過で失敗(当時は未発覚) |
| `cart.py` | 32CCマクロを PC93-95 へ+CC#50 | 同上。3種とも同じ音になった |
| `dbg5.py` | **8CCマクロを PC93-95 へ(cart_setup_v3)**+共通土台+確認 | **成功** |
| `cal.py` | コントローラー校正(PC89-128 全部に無音マクロ)、PC1-40 試聴、10CC版(v4) | 未報告 |

## 検証(dbg)

| ファイル | 調べたこと | 結果 |
|---|---|---|
| `dbg.py` | dbg1 PC1-4 / dbg2 CC#70 / dbg3 基本マクロ / dbg4 ユーザーマクロ記録 / dbg5 PC割り当て(PC92-94を試す) | dbg3 のみ変化なし。dbg5 は PC93, PC94 で反応 |
| `dbg2.py` | dbg6 4/8/16CC の容量 / dbg7 32CC ゆっくり / dbg8 32CC 速く | 全部「変化あり」だが判定設計が悪く、容量は測れていなかった |
| `dbg3.py` | dbg9 無音で二択判定(直接実行 / PC経由)、cart_setup_v2 | dbg9 成功。v2 は容量超過で失敗 |
| `dbg4.py` | dbg10 無音CCを 2,3,4,8,16,32 番目に配置 | 8まで成功、16以降失敗 |
| `dbg5.py` | dbg11 無音CCを 9〜15 番目に配置 | **10まで成功、11以降失敗 → 容量10** |
