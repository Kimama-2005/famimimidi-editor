## ソフトウェア

- **Domino**(Windows用の無料MIDIシーケンサー)。CCの直接入力、MIDIスルー、ループ再生で使用中。
  - ポートAの MIDI OUT デバイスにUSB-MIDIインターフェースを設定済み。
  - 一覧に無いCC番号は、イベントリストでCC行を**1回クリック→数字キー入力**で直接入力できる。
  - 音源定義ファイル(XML)を自作すると、CC名をDominoの画面に出せる。本ソフトから生成できると便利(要件案に記載)。
  - **1トラックに複数チャンネルが混ざったSMFは読み込みを拒否する**(「1トラック内に複数のチャンネルが混合しています。読み込みを中止します。」)。チャンネルごとにトラックを分けること。
- **Cubase**(エディション未確認)。実機音の録音と書き出しの相談をした。外部インストゥルメント機能はPro版のみ。

## 接続構成

### A. 現在の開発・検証構成(PCを挟む)
```
KROSS2 MIDI OUT ──> USB-MIDI I/F MIDI IN ──USB──> PC (Domino)
PC (Domino) ──USB──> USB-MIDI I/F MIDI OUT ──> ふぁみみみっでぃ MIDI IN
```
Dominoの MIDI-IN スルーで KROSS2 の演奏をそのまま流している。

### B. 直結構成(PCなし)
```
KROSS2 MIDI OUT ──> ふぁみみみっでぃ MIDI IN
```
ユーザーの最終的な理想は「音色をカートリッジに保存し、ファミコンのコントローラーか KROSS2 で切り替える」こと。

## 本ソフトを動かす際の注意

- Windows の従来の MIDI ドライバでは、**1つのMIDIポートを同時に1つのアプリしか開けない**場合がある。本ソフトとDomino/Cubaseを同時に開くと、後から開いた方がポートを取れない。エラー時にこれを案内すること。
  - 回避策の候補: 使わない側のアプリを閉じる / 仮想MIDIケーブル(loopMIDI など)を経由する / Windows MIDI Services(マルチクライアント対応)が入っていれば利用。
- Claude Code がクラウド上で動いている場合、MIDI機器にはアクセスできない。実機テストはユーザーのPC上で行う。
- ファミコンの音はモノラル1系統で、5チャンネルが混ざって出てくる。

## 音声の取り出し(参考)

初代ファミコンは RF 出力のみ。録音するには AV 化改造、またはカートリッジ端子45ピン(SOUND IN)からの取り出しが必要。45ピン直取りはノイズが乗りやすいという報告がある。
