# 04 音作りのノウハウ

ソフトのプリセット、ツールチップ、ヘルプに使える知識。実機で確認済みの内容と、実装表からの解釈が混ざっているので、解釈には印を付けた。

## パラメーターの実際の効き方

### デューティ比(CC#70 / PC1〜4、ch1,2のみ)
フィルターの無い音源なので、パルス波の音色はほぼデューティ比で決まる。
- 12.5%(16):一番細く鋭い。混んだ伴奏の中でも抜ける
- 25%(48):ファミコンのメインメロディの定番。鼻にかかった芯のある音
- 50%(80):丸くオルガン寄り。初期値
- 75%(112):25%の波形を反転しただけなので、聴感は25%とほぼ同じ

### エンベロープ
- **CC#75(ディケイ・タイム)は、CC#79(サスティン・レベル)が127未満のときだけ意味がある。** 減衰先がサスティン・レベルなので、127のままだと何も起きない。0は「瞬時にサスティン・レベルへ」。
  - 事前調査の途中で「CC#75=0は減衰しない」と誤って説明していた。上記が正しい。
- 打楽器的な音 = CC#79=0 + CC#75を小さめ(5〜20)。
- 「弾いた感じ」のリード = CC#79を少し下げる(96〜112)+ CC#75=10〜20。127だと電子オルガンのように平坦になる。
- 【解釈】CC#73(アタック・タイム)は CC#12(アタック・レベル)から最大音量まで上がる時間。CC#73=0 ならCC#12は効かない。柔らかい立ち上がり = CC#12=40〜60 + CC#73=10〜20。
- 時間系(CC#72/73/75/78/83)は**指数的**に伸びる。まず20〜50で試すのが実用的。100を超えると急に長くなる。

### ビブラート
- 【解釈】CC#1(モジュレーション量)が CC#81(不感帯、初期値20)を超えたときに掛かる。常時ビブラートにするなら CC#1=60〜80 を送っておく。
- CC#78(ディレイ)で**遅らせる**のが最重要。短い音は揺れず、伸ばした音だけ歌う。34〜54が使いやすい。
- CC#77(デプス)の最小の非ゼロ値は1。これより浅くしたいときは CC#1 を下げる。
- CC#76(レート)5〜8Hzが歌のビブラートの速さ。
- CC#80(波形)を Pulse(3,4)にしてデプスを上げると、2音を往復するトリル/効果音になる。
- CC#30(アフタータッチ・タイプ)=1 なら、鍵盤を押し込むとビブラートが深くなる。=2でチョーキング風のピッチアップ。

### トレモロ(ch1,2,4)
- CC#92 はモジュレーションホイールと同じ使い方(深さのリアルタイム操作)。
- CC#88 を Pulse 系(6,7)にすると音量がブツ切りになり、ゲート的な効果になる。
- 常時うっすら掛ける(CC#92=10〜18)と、音に揺らぎと輝きが出る。

### アルペジエーター(単音chで和音を作る)
- CC#23=127(2音以上で作動)、CC#24=3〜6(約24〜48ms)で、押した和音が高速で巡回して**和音に聞こえる**。ファミコン時代のチップチューン特有のビリビリした和音。
- CC#24 を 3 → 10 → 20 → 40 と上げると、和音からアルペジオ(分散和音)へ連続的に変わる。
- CC#26=6(Random)は混沌としたSE風。CC#27でオクターブ範囲を広げると派手になる。
- アルペジエーターONのとき CC#22(ノート記憶)は効かない。

### ポルタメント
- CC#65=127 で ON、CC#5 で時間。CC#84=1〜63 で「下から」、64〜127 で「上から」しゃくり上げて入る。
- ごく短く(CC#5=3〜6)入れるとレガートが自然になる。

### ノイズ(ch4)でドラムキットを作る
- ch4は単音で、エンベロープも1組しかない。**ヒットの直前(約12tick前)に CC#75 を送り直して**、楽器ごとに減衰を変える。
- ノート番号がノイズの周期。0〜63が長周期(ザーという砂っぽい音)、64〜127が短周期(金属的なブザー)。16ごとに繰り返し、番号が小さいほど高い。
- 実用値(`data/patches.json` の `drum_kits`):キック=15、スネア=6、タム=9、クローズドハット=1、オープンハット/クラッシュ=0(CC#75を長く)。
- キックは三角波ch3の極低音(ノート26、約40ms)で鳴らすと芯が出る。実機のファミコン音楽がやっていた手法。キックの瞬間だけベースを退避させる。

### 2chを使った厚み
- ch2でch1と同じフレーズを16分遅れ・1オクターブ下・音量控えめで鳴らすとエコー。
- ch2だけ CC#85(デチューン)=70 前後にすると、ダブリングの厚みが出る(1あたり1cent)。

## 音色の設計例

`data/patches.json` に以下が入っている。
- **J-POP リード 3種**(標準25% / バラード50% / サビ12.5%)。単音前提、遅れビブラート。32CC版と、マクロ用10CC版。
- **Tim Follin 風**:高速アルペジオのリード、エコー、三角波ベース、ノイズ/DPCMドラム。ループ曲も作った(reference参照)。
- **疑似ギター 2種**(歪みパワーコード / クリーンアルペジオ)。
- ノイズドラムキット、三角波キック。

## シームレスに音色を切り替えるには

| 方法 | 所要時間 | 備考 |
|---|---|---|
| CC#121 + 全設定 | 30ms以上 + **音が止まる** | 使わない |
| リセット無しで全32CCを送る | 約30ms | 休符に置けば可。**全音色が同じCC番号を全部書く**ことで前の設定が残らない |
| 差分のCCだけ送る | 10〜15ms | 今どの音色かを管理しないと壊れる |
| マクロ + PC | **約0.6ms** | カートリッジ保存。1マクロ10CCまで。共通の土台は別途送る |

マクロ方式でも、マクロに入らない「共通の土台」は電源投入後に一度送る必要がある。電源ON時の既定値と違うものだけでよい(J-POPリードの場合は CC#77=1、CC#76、CC#3=0、CC#12、CC#5、CC#82 程度)。
