# 02 MIDI仕様の要点

完全な定義は `data/famimimidi_spec.json`、原本は `docs/Famimimidi_implement_chart_v10.pdf`(ファミコン版・日本語)。
ここではソフトを作る上で効いてくる点だけをまとめる。

## チャンネル構成

| ch | 音源 | 音域(ノート番号) | ベロシティ |
|---|---|---|---|
| 1 | パルス波1 | 33〜108(32以下は無反応) | 16段階 |
| 2 | パルス波2 | 33〜108 | 16段階 |
| 3 | 三角波 | 21〜96(20以下は無反応) | ON/OFFのみ |
| 4 | ノイズ | 0〜127(ノイズマップ) | 16段階 |
| 5 | DPCM / 波形メモリ | 0〜127(DPCMマップ) | DPCM:ON/OFF、波形メモリ:32段階 |

- 全チャンネル**単音**(Mode4固定)。同じchで2音押すと、後着優先。CC#22(ノート記憶)がONなら、後の音を離すと前の音に戻る。
- 電源投入時にBボタンを押していると ch6〜10、A+Bで ch11〜15 に応答する。ソフト側は**チャンネルオフセット**を設定できるようにする。
- 高音域では周波数誤差がある。
- ノートオフのベロシティは無視される。

## CCの値の種類(UIの作り分けに直結)

`famimimidi_spec.json` の `kind` フィールド:

| kind | 意味 | UI案 | 送る値 |
|---|---|---|---|
| `continuous` | 0〜127の連続値 | スライダー | そのまま |
| `time_exp` | 時間。**指数的に増える**(127で約10秒、CC#5は約5秒) | スライダー+ms目安表示 | そのまま |
| `steps` | N段階を0〜127に均等割り振り | 段階セレクター | 段階kの中央値 `floor(k*128/N + 64/N)` |
| `enum` | 0〜Mを直接指定(M+1〜127は均等割り振り) | ドロップダウン | インデックスをそのまま |
| `switch` | 0〜63=OFF / 64〜127=ON | トグル | 0 か 127 |
| `special` | 範囲ごとに意味が違う(CC#9, CC#84) | 個別UI | 個別 |
| `action` | 実行系(マクロ、リセットなど) | ボタン | 個別 |
| `macro_ref` | マクロ番号を指定(CC#52〜59) | マクロ選択 | マクロ番号 |

段階の中央値の例: 4段階(CC#70デューティ)= 16/48/80/112、16段階(CC#79など)= 4,12,20,...,124、8段階(CC#15/16)= 8,24,...,120。

**チャンネルによって効かないCCが多い**(`channels` フィールド)。例: デューティ CC#70 は ch1,2 のみ、サスティン・レベル CC#79 は ch1,2,4,5 のみ(三角波には無い)。UIでは効かないパラメーターを隠すかグレーアウトする。

## プログラムチェンジ

| PC(1始まり) | データバイト | 内容 |
|---|---|---|
| 1〜4 | 0〜3 | ch1,2のデューティ比 12.5/25/50/75% |
| 4〜(5以降) | 4〜 | 工場プリセット「いろいろな音色」。中身は非公開・未調査 |
| 61〜76 | 60〜75 | ユーザー波形メモリ(SysExで登録、ch5のみ、保存される) |
| 89〜128 | 88〜127 | **ユーザーマクロ(CC#51で登録、全chで共通、保存される)** |

初期値: ch1,2=PC3、ch3,4=PC1、ch5=PC8(受信時の初期値。コントローラー内部のカウンタの開始値とは限らない。`03` 参照)。

表記の混乱を避けるため、UIでは「PC93(送信値92)」のように**両方**を表示する。

## マクロ関連CC

| CC | 役割 | 値 |
|---|---|---|
| 45 | ユーザーマクロ記録 | 1〜40=記録開始 / 0=**記録停止+保存** |
| 46 | 基本マクロ実行 | 1〜127 |
| 47 | ユーザーマクロ実行 | 1〜40 |
| 48 | Exマクロ実行 | 1〜87 |
| 49 | マクロ切り替え | 46=基本 / 47=ユーザー / 48=Ex。CC#52〜59を設定すると46に戻る |
| 50 | 初期化マクロ設定 | 1〜5=指定chの電源ONマクロに「最後に実行したマクロ」を設定(保存) |
| 51 | PCマクロ設定 | 88〜127=PC89〜128に「最後に実行したマクロ」を設定(保存) |
| 52〜59 | エンベロープ段階マクロ | アタック/ディケイ/サスティン/リリース/モジュレーション周期/トレモロ周期/ポルタメント開始/終了 で指定マクロを実行 |

CC#50と#51は「**最後に実行したマクロ**」が対象。記録しただけでは対象にならないので、記録後にCC#47で一度実行してから割り当てる。

## SysEx(ch5 波形メモリ)

```
波形データ:  F0 00 70 7F d0 d1 ... d15 F7     (d = 00〜0F、2バイト目の00は任意ID 00〜7D)
PC登録:      F0 00 71 7F NN F7                (NN = 60〜75 → PC61〜76。-1に注意。保存される)
例(のこぎり): F0 00 70 7F 00 01 02 03 04 05 06 07 08 09 0A 0B 0C 0D 0E 0F F7
```
波形メモリモード(CC#18)と解像度(CC#19)は実装表で「テスト機能」扱い。

## 非対応

ユニバーサルSysEx、ソング・ポジション/セレクト、チューン、タイミング・クロック、アクティブ・センシング、ローカルON/OFF、システム・リセット(本体のリセットボタンか電源再投入のみ)。**クロック同期は無い。**

## その他のメッセージ

- CC#120 オール・サウンド・オフ
- CC#121 リセット・オール・コントローラー: **全音停止**+全CC/PC/PB初期化
- CC#123 オール・ノート・オフ(三角波は即時停止)
- パニックボタンには CC#123 → CC#120 を使い、CC#121 は「初期化」ボタンとして分ける。

## ファミコン版とNES版の実装表の違い

ネット上にはNES版(英語)の実装表もある。事前調査の途中までNES版を参照していたので注意。

| 項目 | ファミコン版(正) | NES版 |
|---|---|---|
| CC#45=0 | 記録停止**+保存** | Stop recording |
| CC#48 範囲 | 1〜87 | 1〜127 |
| CC#50 | 1〜5で**ch指定** | 1-5ch(意味が曖昧) |
| CC#77 | ±0〜±127**半音**(初期値2=200cent) | 0-127 (x100cent) |
| CC#21 | ホールド・タイム**自動設定** | Auto Hold |
| NES版のみ | 電源投入時のリージョンチェック | — |
