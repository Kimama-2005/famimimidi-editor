# 「整える」(共通の土台+切り替えの後始末)の実機確認

**カートリッジに書き込みます**(ch1 の音色5つの保存し直しと、ch1 の「電源を入れたときの音色」を土台にする)。約30秒。
判定は「1音だけ / 複数の音(ビリビリ入れ替わる)」の二択です。

準備: Domino / Cubase を閉じる → `run.bat` → 「★ カートリッジに音色を保存(かんたん)」を開く

---

## A. 整える前の確認(問題が起きることを確かめる)
1. 左で **場所13(101)Tim Follin風** を選び、「♪ 呼び出して鳴らす」→ 最後の和音が**複数の音**になるのを確認
2. 続けて **場所5(93)J-POP リード 標準** を選び、「♪ 呼び出して鳴らす」
- 判定(A): 最後の和音が **複数の音(ビリビリ)** → はい / いいえ
  (はい = 今は Follin のアルペジエーターが残ってしまう。これを直すのが「整える」)

## B. 整える
1. 画面下の「音色の切り替えを整える」で **ch1 の「整える…」** → 確認画面を読む → チェック →「整える」
2. 「書き込み完了」が出たら、**ファミコンの電源を入れ直す**
- 判定(B): ch1 の行が「整っています…」になった → はい / いいえ

## C. 整えた後
1. **場所13(101)Tim Follin風** →「♪ 呼び出して鳴らす」→ 和音
- 判定(C1): **複数の音** → はい / いいえ(Follin 自身のアルペジオが残っているか)
2. 続けて **場所5(93)J-POP リード 標準** →「♪ 呼び出して鳴らす」→ 和音
- 判定(C2): **1音だけ** → はい / いいえ(アルペジエーターが切れたか)
3. **場所10(98)疑似ギター 歪み** →「♪ 呼び出して鳴らす」→ 和音
- 判定(C3): **複数の音** → はい / いいえ
4. 続けて **場所6(94)J-POP リード バラード** →「♪ 呼び出して鳴らす」→ 和音
- 判定(C4): **1音だけ** → はい / いいえ

C2 Follin→J-POP標準 1音: はい/いいえ
C3 ギター 複数音: はい/いいえ
