# V0: 音量(ボリューム)を0にしても鳴るか

報告(2026-11-05): コードモードで 1・2・3・5 の音量を全部0にしても、**強く弾くと音程のある音が鳴る。鳴らないときもあり、法則が分からない**
- ログ: アプリは ch1・ch2・ch3・ch5 だけに送り、4つとも CC#7=0 を送ってある。スルーを切ると鳴らない(アプリから出ている)
- アルペジエーター方式(三角波と ch1 だけ)では鳴らない → 残っているのは ch2 か ch5(波形メモリ)
- 先に入れた対策: **アプリは音量0の ch にノートオンを送らない**(ふぁみみみっでぃ側の性質があっても鳴らない)

このテストは、手の強さのばらつきをなくすために、**決まった強さを決まった回数だけ**送ります。どの ch が、どの強さで鳴るのかを調べます。

## 準備
1. アプリで「5 DPCM/波形メモリ」タブの波形を「三角」にする(ch5 に波形を送る)→ **アプリを閉じる**(Domino がポートを使えるように)
2. **Cubase も閉じる**。Domino で `hw_tests\out\V0_volume_zero.mid` を開く(出力 = USB MIDI Interface)

## 流れ(約50秒)
ch1 → ch2 → ch3(三角波)→ ch5(波形メモリ)の順に、次をくり返します。
1. 区切りの音: ノイズ「チッ、チッ」
2. その ch の音量を0にして、**強さ127 で4回**(ポーン×4 のつもり)
3. 1秒あけて **強さ64 で4回**

**ノイズの区切りのあとに、音程のある音が何回聞こえたか**を数えてください(聞こえなければ 0)。

```
ch1: 強127= /4  強64= /4
ch2: 強127= /4  強64= /4
ch3: 強127= /4  強64= /4
ch5: 強127= /4  強64= /4
```

最後に、4つの ch の音量は最大に戻ります。
