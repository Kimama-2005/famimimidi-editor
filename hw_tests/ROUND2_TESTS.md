# 第2回 実機テスト チェックリスト

ファイルは `hw_tests/out/` にあります(`python hw_tests/make_tests.py` で再生成できます)。
各 `.mid` と同じ名前の `.txt` に、送るバイトと時刻の一覧があります。

**上から順番どおりに**実施してください。T7・T6 はカートリッジの一部を書き換えるので、最後に必ず R2 で元に戻します。

共通の注意(前回と同じ):
- 再生中は KROSS2 の音色(プログラム)を切り替えない。
- KROSS2 は **ch1** で送信する設定のまま。
- 「電源を入れ直す」= ファミコンの電源を切って、数秒待って入れる。

## T2b 1つのマクロで複数チャンネルを変えられるか(U4)

前回の T2 を、Domino で読めるようにチャンネルごとのトラックに分けたものです。中身は同じです。

- ファイル: `T2b_multichannel.mid`(約10秒)
- 書き換えるもの: マクロ10(未使用の番号。どのPCにも割り当てない)
- 手順: 再生する → 終わったら**電源を入れ直す**
- 判定: 後半(2回目のフレーズ)で
  - (a) ノイズ(ザッザッ)が**消えた**か → はい / いいえ  ← こちらが本命
  - (b) メロディが**細い音**になったか → はい / いいえ

## T7 コントローラーで正確にどのPCに着くか(U1)

前回の T5 では、PC89〜128 を全部無音にしたため、← で戻っても音量が 0 のまま戻りませんでした(PC を変えても音量は保持される)。
今回は **PC89 だけを無音**にし、PC90〜128 は「音量最大」のままにします。これで ← を押していって、**PC89 に着いた瞬間だけ**音が消えます。

- ファイル: `T7_mute_pc89_only.mid`(約5秒、音は鳴らない)
- 書き換えるもの: マクロ20(無音)を PC89 に割り当て
- 手順:
  1. `T7_mute_pc89_only.mid` を再生する
  2. **電源を入れ直す**
  3. KROSS2 で1音弾く → 鳴るはず(鳴らなければそこで中止して報告)
  4. コントローラーで **SELECT+→ を9回**押す。1音弾く
     - **無音**なら K=0 として手順6へ
  5. SELECT を離して、**← を1回押す → 1音弾く**を繰り返す。**無音になったら止めて**、← を押した回数 K を数える(最大45回。45回で消えなければ「消えず」)
  6. 止まったら次の T6 へ(音は無音のままで構いません。T6 の手順で電源を入れ直します)
- 判定:
  - K = ___ 回(または「消えず」)
  - 途中で音色が変わるのは構いません(PC93〜95 は J-POP リード)。見るのは「消えたかどうか」だけです。

## T6 電源ONマクロ(CC#50)は効くか(U3)

前回の T1(a) は「揺れるかどうか」という聴き分けが必要な判定でした。今回は **ch1 の電源ONマクロを「無音」**にして、電源を入れた直後に鳴るか鳴らないかで判定します。

- ファイル: `T6_startup_mute.mid`(約5秒、音は鳴らない)
- 書き換えるもの: ch1 の電源ONマクロ → マクロ20(無音)
- 手順:
  1. `T6_startup_mute.mid` を再生する
  2. **電源を入れ直す**
  3. **何も再生せずに**、KROSS2 で1音弾く
- 判定:
  - 手順3で **無音** だったか → はい / いいえ
    - はい = CC#50 は効く
    - いいえ(鳴った)= CC#50 は効いていない

## R2 元に戻す(必須)

- ファイル: `R2_restore.mid`(約4秒)
- 戻すもの: PC89 → マクロ19(音量最大)、ch1 の電源ONマクロ → マクロ11(J-POP 標準)。前回 T0 の後と同じ状態になります。
- 手順:
  1. `R2_restore.mid` を再生する
  2. **電源を入れ直す**
  3. KROSS2 で1音弾く
- 判定: 鳴った → はい / いいえ(いいえ なら、T0 をもう一度再生して報告してください)
