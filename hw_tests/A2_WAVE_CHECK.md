# A2: 波形メモリエディタの実機確認

**B でカートリッジに書き込みます**(波形を PC61・PC62 に登録)。PC61〜76 は、これまで一度も使っていない場所です。
判定はすべて「鳴った / 無音」です。「平ら(無音)」の波形は形が平らなので、音になりません。これを判定に使います。

準備: Domino / Cubase を閉じる → ファミコンの電源を入れ直す → `run.bat` → 上の段の「**波形メモリ(ch5)…**」

---

## A. 試しに鳴らす(保存しない)
1. 「形を選ぶ」で **矩形 50%** →「♪ 鳴らす」
- 判定(A1): **鳴った** → はい / いいえ
2. **平ら(無音)** →「♪ 鳴らす」
- 判定(A2): **無音** → はい / いいえ
3. もう一度 **矩形 50%** →「♪ 鳴らす」
- 判定(A3): **鳴った** → はい / いいえ
   (A1〜A3 が「はい」なら、描いた形がその場で音に反映されている)

## B. 登録する(書き込み)
1. **平ら(無音)** を選ぶ → 名前「平ら」→ 登録先 **PC61** →「登録…」→ 確認 → 登録する
2. **矩形 50%** を選ぶ → 名前「矩形50」→ 登録先 **PC62** →「登録…」→ 確認 → 登録する
- 判定(B): 2回とも「登録しました」が出た → はい / いいえ

## C. 電源を切っても残るか
1. **ファミコンの電源を入れ直す**
2. 登録先で **PC62** を選び、「登録したものを呼び出して鳴らす」
- 判定(C1): **鳴った** → はい / いいえ
3. 登録先で **PC61** を選び、「登録したものを呼び出して鳴らす」
- 判定(C2): **無音** → はい / いいえ
4. もう一度 **PC62** を呼び出して鳴らす
- 判定(C3): **鳴った** → はい / いいえ
5. 終わったら「ch5 をドラムに戻す」

(C1〜C3 が「はい」なら、登録が保存され、PC で呼び出せる)

---

## 報告
```
A1= A2= A3= B= C1= C2= C3=
```
PC61 の「平ら」は、あとで好きな波形で上書きして構いません。
