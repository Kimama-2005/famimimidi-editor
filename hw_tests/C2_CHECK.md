# C2: 新しい画面の音色エディタの確認

**カートリッジへの書き込みはありません。** 判定はすべて二択です。
準備: `run.bat` で起動 → 「1 パルス波1」タブ → 表示は「かんたん」

| # | 手順 | 判定 |
|---|---|---|
| A | おまかせ「ピアノ風(減衰)」→「この音にする」→ microKEY2 で1音を長押し | 押している間にだんだん消えた → はい/いいえ |
| B | エンベロープのグラフで、真ん中の白い点(サスティン)を**一番上**までドラッグ → 長押し | 押している間ずっと鳴り続けた → はい/いいえ |
| C | 右端の白い点(リリース)を**右いっぱい**までドラッグ → 短く弾いて離す | 離した後も余韻が長く残った → はい/いいえ |
| D | 「ビブラート」のスイッチを入れる → 長押し | 少し遅れて音程が揺れ始めた → はい/いいえ |
| E | 「アルペジエーター」を「2ノート以上」にして、microKEY2 で和音(3音)を押さえる | 音がビリビリ入れ替わった → はい/いいえ |
| F | 右上の「詳細」→ CC#7 ボリュームのつまみを左端(0)にして弾く | 無音 → はい/いいえ(終わったら「既定値に戻す」) |
| G | 「3 三角波」タブ | 「デューティ比」のカードが無く、エンベロープに真ん中の点が無い → はい/いいえ |

```
A= B= C= D= E= F= G=
```
操作しにくい所、見づらい所があれば教えてください(特にエンベロープのつまみ心地)。
