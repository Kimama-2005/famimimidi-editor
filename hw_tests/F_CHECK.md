# フェーズF の確認: コードモード

鍵盤1本指でコードを鳴らすモードです(オタマコードと同じ配置)。**カートリッジへの書き込みはありません。**
声の割り当て: 三角波(ch3)= ベース、パルス1(ch1)・パルス2(ch2)・波形メモリ(ch5)= 上の3声。

準備:
1. ファミコンの電源を入れ直す → アプリを閉じて `run.bat` で起動し直す
2. 「波形メモリ」画面で「三角」を選んで「♪ 鳴らす」を1回押す(ch5 に波形を送っておく。送らないと ch5 が無音のことがある)→ 閉じる
3. 上の「🎸 コード」を押してコードの画面を開く

## 追加(2026-11-04): 上の方の鍵盤の確認

最初の確認で「コードモードより上の鍵盤がおかしい」と報告 → ログを見ると、**C6+C3 でコードモードが意図せず OFF になっていた**
(OFF の間は、演奏セット「ファッションモンスター1」の割り当て表どおり F5 から上が ch2+ch4(ノイズ)で鳴る)。
→ C6+C3 での切り替えをやめた(スペースキーと画面のボタンだけ)。画面の鍵盤も、割り当て表のときは外部の鍵盤と同じ ch で鳴るようにした。

| # | 手順 | 判定 |
|---|---|---|
| K | スペースキーで ON → C6 を押したまま C3 を押す → 離す | 画面の「コードモード」が ON のまま → はい/いいえ |
| L | オクターブ UP で、C#6〜C7 の上の鍵盤と、さらに上(C#7〜C8)を順に押す | ノイズや単音が鳴らない(機能キーは画面の表示が変わるだけ)→ はい/いいえ |
| M | オクターブを元に戻して C3 を押す → オクターブ UP → **A#6**(全部停止)を押す | 音が止まり、画面の「コードモード」は ON のまま → はい/いいえ |
| N | スペースキーで OFF → 画面の鍵盤で F5 より上を押す | microKEY2 で同じ鍵を押したときと同じ音(パルス+ノイズ)が鳴る → はい/いいえ |

結果(2026-11-04): K・N OK。L・M は Cubase・Domino を閉じたら OK(ほかのソフトが鍵盤を直接流していた)。

## 追加(2026-11-04): つなぎの猶予

報告: 「コードチェンジにも効かせる」は重ねて押したときは効くが、重ねずに持ち替えると効かない
→ ログ: 離した瞬間に全部止め、55ms 後に次のコードを最初から鳴らし直していた
→ 「つなぎの猶予」(初期値 80ms)を追加。全部離してもこの時間は止めず、その間に次を押せばコードチェンジとして扱う

| # | 手順 | 判定 |
|---|---|---|
| O | 「入りの広がり」を 300ms くらい、「コードチェンジにも効かせる」にチェック → C3 を押す → **離してから**すぐ F3 を押す(重ねない) | 音が途切れず、ずれながら F に変わる → はい/いいえ |
| P | F3 を離して何も押さない | すぐ(一瞬で)止まる → はい/いいえ |

```
O= P=
```
結果(2026-11-04): A〜J、O・P すべて合格。**フェーズF 完了**

メモ:
- 「読み込み…」で、オタマの `デスクトップ\オタマコード\chordsets\ライブセット_2026-10.json` をそのまま読み込めます(12曲と4段目)。
- 曲・キーは C6 を押したまま C4〜B4(曲)/C5〜B5(キー)。移調は UP の C#6(−)/D#6(+)。
- 切り替えはスペースキーと画面のボタンだけ(オタマの C6+C3 は入れていない)。
- コードモードの設定(方式・入り方・グライドなど)は、演奏セットを保存すると一緒に保存されます。
- コードモードの間だけ変える設定(ch5 の波形メモリモード、ポルタメント、アルペジエーター)は、OFF にすると音色の値に戻します。
