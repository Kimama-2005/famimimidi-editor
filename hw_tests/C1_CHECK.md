# C1: 新しい画面の土台の確認

新しい画面は、まだ「接続・設定・鍵盤・送信ログ・パニック」だけです(音色の編集は C2 で作ります)。
**カートリッジへの書き込みはありません。** 判定はすべて二択です。

準備: Domino / Cubase を閉じる → ファミコンの電源を入れ直す → **`run.bat`** をダブルクリック
(予備の今までの画面は `run_classic.bat` で起動できます)

| # | 手順 | 判定 |
|---|---|---|
| A | `run.bat` をダブルクリック | 黒い画面に白い枠の「FAMIMIMIDI SOUND EDITOR」が開いた → はい/いいえ |
| B | 何もしない | 上の帯が緑で「USB MIDI Interface に接続中」になっている(前回のポートに自動接続)→ はい/いいえ |
| C | microKEY2 で弾く(1 パルス波1 のタブ) | 鳴った → はい/いいえ |
| D | 画面下の鍵盤をマウスで押す | 押している間だけ鳴った → はい/いいえ |
| E | 上のタブで「4 ノイズ」を選んで microKEY2 で弾く | 音程のない「ザー」という音になった → はい/いいえ |
| F | microKEY2 の鍵盤を押したまま、右上の「パニック」を押す | 押したままなのに止まった → はい/いいえ |
| G | 「見た目(テーマ)」で B を選ぶ → 画面を閉じて `run.bat` で開き直す | B の配色で開いた → はい/いいえ |
| H | 「送信ログ」 | 弾いた内容(ノートON など)が緑の文字で流れている → はい/いいえ |

```
A= B= C= D= E= F= G= H=
```
