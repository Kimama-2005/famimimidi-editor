# 鍵盤の弾き方「ch1+ch2 で重ねる」の確認

同じ音を ch1 と ch2 の両方で鳴らす機能です。**カートリッジへの書き込みはありません。**

準備: `run.bat` → 「1 パルス波1」タブ →「⚙ 接続と設定」。「鍵盤を分ける」はチェックを外しておく。

| # | 手順 | 判定 |
|---|---|---|
| A | 「鍵盤の弾き方」を **ch1+ch2 で重ねる** にする → 「1 パルス波1」タブの「基本」の**ボリュームを0**にして、microKEY2 で C4 を押す | 鳴る(ch2 だけで鳴っている)→ はい/いいえ |
| B | 「2 パルス波2」タブの「基本」の**ボリュームも0**にして C4 を押す | 無音 → はい/いいえ |
| C | ch1・ch2 とも**ボリュームを最大に戻す** → 「ch1 の音色を ch2 にコピーして少しずらす」を押す → C4 を長押し | うねり(ゆっくり周期的に揺れる感じ)が聞こえる → はい/いいえ |
| D | 「鍵盤を分ける」にチェック(下のch「ch3 三角波」)→ 左手で C4 より下、右手で上を同時に押す | 2つ一緒に鳴る → はい/いいえ |
| E | 「鍵盤を分ける」を外し、「開いているタブのchで鳴らす」に戻す | (戻すだけ) |

```
A= B= C= D=
```

メモ:
- 重ねるのは1音です(2つ押すと、後から押した音になります)。
- ch2 のデューティ比を ch1 と変える(例: ch1 50%、ch2 25%)と、また違う厚みになります。
- C の「うねり」はわざと音程を少しずらしたもので、アンプの歪みとは別です(パルスどうしならアンプは歪まないことを確認済み)。

## 追加: ずらす量の選択(2026-10-01)

「ch1 の音色を ch2 にコピーしてずらす」の横で、ずらす量を **少し(8)/普通(16、初期値)/強め(24)** から選べます。
計算では、「少し」は D5・A5・B5 で音程の段階に丸められて、ずれが0になります(うねらない)。「普通」なら1段以上ずれます。

準備: 「ch1+ch2 で重ねる」、「鍵盤を分ける」はチェックを外す、ch1・ch2 のボリュームは最大。

| # | 手順 | 判定 |
|---|---|---|
| F | 「少し」を選んで「コピーしてずらす」→ **D5** を3秒ほど長押し | うねりが分からない → はい/いいえ |
| G | 「普通」を選んで「コピーしてずらす」→ **D5** を3秒ほど長押し | うねりが聞こえる → はい/いいえ |
| H | 「強め」を選んで「コピーしてずらす」→ **D5** を3秒ほど長押し | G より速くうねる → はい/いいえ |

```
F= G= H=
```
