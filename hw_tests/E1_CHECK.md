# E1 の確認: 割り当て表と演奏セット

**カートリッジへの書き込みはありません。**

変わったところ:
- 「⚙ 接続と設定」の「鍵盤の弾き方」が「開いているタブのch / **割り当て表で鳴らす** / 鍵盤のchのまま」の3つになりました。
  前の「2音」「重ねる」「鍵盤を分ける」は、**割り当て表**(ch ごとに 使う・鍵域・音の高さ・ホイール)で表します。よく使う形は「ひな形」から選べます。
- ライブラリの上に「音色 / **演奏セット**」の切り替えができました。演奏セット = 5ch の音色 + 割り当て表。

準備: アプリを閉じて `run.bat` で起動し直す →「1 パルス波1」タブ →「⚙ 接続と設定」。

| # | 手順 | 判定 |
|---|---|---|
| A | 「ひな形」で **下 ch3 ベース / 上 ch1+ch2 で2音** を選ぶ → 左手で C4 より下を1つ、右手で C4 と G4 を、3つ同時に押す | 3音鳴る → はい/いいえ |
| B | 「1 パルス波1」タブの「基本」のボリュームを **0** にする(2音なので ch2 も0になる)→ 割り当て表の ch3 の鍵域の**上を G9** にする → C4 より上の鍵を1つ押す | 鳴る(鍵域を重ねたので ch3 も鳴る)→ はい/いいえ |
| C | ch3 の鍵域の上を **B3** に戻す → C4 より上の鍵を1つ押す | 無音 → はい/いいえ |
| D | ch1 のボリュームを**最大に戻す** → ライブラリの「演奏セット」→「新規保存…」で名前「テスト」→ OK | 一覧に「テスト」が出た → はい/いいえ |
| E | 「3 三角波」タブで「基本」のボリュームを **0** にする → 「鍵盤の弾き方」を「開いているタブのch」にする → 「1 パルス波1」タブで C4 より下の鍵を押す | (ch1 で鳴るだけ。判定なし) |
| F | 演奏セットの「テスト」を**ダブルクリック** → C4 より下の鍵を押す | 三角波のベースが鳴る(ch3 の音量がセットの値に戻り、割り当て表も戻った)→ はい/いいえ |
| G | アプリを閉じて `run.bat` で起動し直す → ライブラリの「演奏セット」を開く | 「テスト」が残っていて、鍵盤の上のボタンが「外部鍵盤: ch1+2(2音) C4〜 / ch3 〜B3」になっている → はい/いいえ |

```
A= B= C= D= F= G=
```

メモ:
- 1つの鍵は、鍵域に入るすべての ch で鳴ります(B はそれを使っています)。
- 「ホイール」に印のある ch には、ピッチベンドやモジュレーションも送ります。
- 演奏セットの中の音色はコピーです。元の音色をあとで直しても、セットは変わりません。
- セットのカートリッジへの保存(E2)と、電源を入れたときのセット(E3)は、この確認のあとで作ります。
