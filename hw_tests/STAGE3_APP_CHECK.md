# 段階3(カートリッジ書き込み)アプリの実機確認

**この確認ではカートリッジに書き込みます。** 使う番号は、今どこからも使われていない**マクロ17・18**と、空きの **PC97・PC98** です(J-POP の PC93〜95 には触りません)。
最後の G で、PC97 と ch2 の電源ONマクロを元に戻します。

判定はすべて二択です。「音色の読み込み」はPC上の操作、「書き込み」はカートリッジへの操作です。混同しないように手順どおりに進めてください。

> **2026-09-29 追記**: C(2) は不合格でした(マクロ19が空の疑い。T10 で確認します)。D 以降を続けてください。
> microKEY2 は送信chを変えられないので、上の段の「**開いているタブのchで鳴らす**」にチェックを入れてください(初期値でオン)。
> ch2 タブを開けば microKEY2 の演奏は ch2 で、ch4 タブなら ch4 で鳴ります。画面の鍵盤も、開いているタブのchで鳴ります。

準備:
- Domino / Cubase を閉じる。ファミコンの電源を入れ直す
- `run.bat` で起動(前回のポートに自動接続されます)
- 右上の「カートリッジ対応表…」を開いておく(以下「対応表」)。PCを送るのはこの窓の上の欄です

---

## A. テスト用の音色を作る(PC上だけの操作)
1. 「ch1 パルス波1」タブで「既定値に戻して送る」
2. CC#7 ボリュームを 0 にする
3. ライブラリの「新規保存…」で名前を **書き込みテスト 無音** にして保存
4. CC#7 ボリュームを 127 に戻す
- 判定: ライブラリの説明欄に `CC#7=0 ボリューム` の1行だけが出ている → はい / いいえ

## B. 書き込み(マクロ17 → PC97)
1. 「書き込みテスト 無音」を選び、「カートリッジに書き込み…」
2. マクロ番号で **17** を選ぶ。PC に割り当てる = チェックあり、**PC97** を選ぶ。電源ONマクロ = チェックなし
3. 「内容を確認して書き込む…」→ 確認画面で送信内容を見る → 「取り消せないことを理解しました」にチェック →「書き込む」
- 判定(1): 確認画面で、チェックを入れる前は「書き込む」ボタンが押せなかった → はい / いいえ
- 判定(2): 「書き込み完了」のメッセージが出た → はい / いいえ
- 判定(3): 対応表で PC97 が「マクロ17 書き込みテスト 無音」になった → はい / いいえ

## C. 書き込んだものを呼び出す
1. **電源を入れ直す**
2. ch1 タブの画面鍵盤で1音 → 鳴るはず
3. 対応表で **ch=1、PC=97** を「送信」→ ch1 で1音
- 判定(1): **無音** → はい / いいえ
4. 対応表で **ch=1、PC=96** を「送信」→ ch1 で1音
- 判定(2): **鳴った**(PC96 は音量最大マクロ)→ はい / いいえ

## D. 「全chで共通」の意味(U8)
1. **電源を入れ直す**
2. ch2 タブの画面鍵盤で1音 → 鳴るはず
3. 対応表で **ch=2、PC=97** を送信
4. ch2 タブで1音 → 判定(1): **無音** → はい / いいえ
5. ch1 タブで1音 → 判定(2): **鳴った** → はい / いいえ
   (はい・はい なら「PCの割り当ては全chで共通で、PCを受けたchだけに効く」)

## E. ch4・ch5 でも効くか(U13)
1. **電源を入れ直す**
2. ch4 タブの画面鍵盤で1音(ザッという音)→ 鳴るはず
3. 対応表で **ch=4、PC=97** を送信 → ch4 で1音 → 判定(1): **無音** → はい / いいえ
4. ch5 タブの画面鍵盤で、左端の C(ノート36 = DPCM のバスドラム)を1回 → 鳴るはず
5. 対応表で **ch=5、PC=97** を送信 → ch5 で同じ鍵 → 判定(2): **無音** → はい / いいえ

## F. 電源ONマクロの設定
1. 対応表の下「記録済みのマクロを割り当てる」で、マクロ = **17**、PC のチェックを**外す**、電源ON ch に**チェック**して **2** を選ぶ →「内容を確認して割り当てる…」→ 確認 → 実行
2. **電源を入れ直す**
3. ch2 タブで1音 → 判定(1): **無音** → はい / いいえ
4. ch1 タブで1音 → 判定(2): **鳴った** → はい / いいえ

## G. 元に戻す(必須)
1. 「記録済みのマクロを割り当てる」で、マクロ = **19**、PC のチェックを**外す**、電源ON ch = **2** → 実行
2. 同じ欄で、マクロ = **19**、PC に**チェック**して **PC97**、電源ON ch のチェックを**外す** → 実行
3. **電源を入れ直す**
- 判定: ch2 タブで1音 → **鳴った** → はい / いいえ
- 判定: 対応表で PC97 が「空き(マクロ19 音量最大)」に、電源ON ch2 が「マクロ19」になっている → はい / いいえ

## H. 本物の音色で(アルペジエーターが入るか)
「疑似ギター 歪み/パワーコード」は、マクロに入る10個にアルペジエーター(CC#23〜25)が含まれます。和音を弾いたとき「1音だけ」か「複数音」かで判定できます。
1. 「疑似ギター 歪み/パワーコード」を選び「カートリッジに書き込み…」→ マクロ **18**、**PC98** → 確認 → 書き込む
2. **電源を入れ直す**(ch1 は J-POP 標準 = アルペジエーターOFF)
3. ch1 タブで「和音(3音同時)」→ 1音だけのはず
4. 対応表で **ch=1、PC=98** を送信 →「和音(3音同時)」
- 判定: **複数の音**が高速で入れ替わって聞こえた → はい / いいえ
- (PC98 はこのまま残します。KROSS2 で PC98 を選べば、いつでもこの音色になります)
