# 鍵盤の弾き方(2音・鍵盤を分ける)の確認

ベースとメロディを1人で弾けるように、microKEY2 の演奏を ch に振り分ける機能を付けました。
**カートリッジへの書き込みはありません**(設定はアプリ側だけ)。

準備: ファミコンの電源を入れ直す → `run.bat` → 「1 パルス波1」タブを開く。
設定は「⚙ 接続と設定」の「鍵盤の弾き方」「鍵盤を分ける」にあります(鍵盤の上の「外部鍵盤: …」ボタンからも開けます)。

| # | 手順 | 判定 |
|---|---|---|
| A | 「鍵盤の弾き方」を **ch1+ch2 で2音まで同時に** にする → microKEY2 で C4 と G4 を**同時に押したまま** | 2音(和音)が聞こえる → はい/いいえ |
| B | 和音や速いフレーズを好きに10秒ほど弾いて、指を全部離す | 鳴りっぱなしの音が残らない → はい/いいえ |
| C | 「1 パルス波1」タブの「基本」の **ボリュームを一番左(0)** にする → C4 と G4 を同時に押す | 2音とも無音(ch2 にも同じ音色が入っている)→ はい/いいえ |
| D | ボリューム0のまま、「鍵盤を分ける」に**チェック**(境目 C4、下のch「ch3 三角波」、下の音を「そのまま」)→ C4 より**下**の鍵を1つ押す | 鳴る(ch3 で鳴っている)→ はい/いいえ |
| E | 続けて C4 より**上**の鍵を1つ押す | 無音(上は ch1/ch2 のまま)→ はい/いいえ |
| F | ch1 の**ボリュームを一番右(最大)に戻す** → 左手で C4 より下、右手で上の2つを同時に押す | 2つ一緒に鳴る(ベース+メロディ)→ はい/いいえ |
| G | 「鍵盤を分ける」のチェックを外し、「鍵盤の弾き方」を **開いているタブのchで鳴らす** に戻す → C4 と G4 を同時に押す | 1音だけ(これまでどおり)→ はい/いいえ |

```
A= B= C= D= E= F= G=
```

メモ:
- 3音目を押すと、一番古い音が止まって新しい音が鳴ります。
- 2音にしている間は、ch1 で変えた音色が ch2 にも自動で入ります(ch2 タブを開くとお知らせが出ます)。
- 下の鍵域の音色は、「3 三角波」タブで作ります。
- ピッチベンドやモジュレーションは、上の鍵域(メロディ)の ch にだけ送ります。
- 「下の音を」でオクターブをずらせます。microKEY2 の鍵盤が短いときに使ってください。
