## T8 SELECT+→ ×9 が PC89 か、→ が +1 か(U1 の確認)

- ファイル: `T8_pc89_neutral_pc90_mute.mid`(約4秒、音は鳴らない)
- 書き換えるもの: PC89 → 音量最大マクロ(今と同じ)、**PC90 → 無音マクロ**(一時的)
- 手順:
  1. `T8_pc89_neutral_pc90_mute.mid` を再生する → **電源を入れ直す**
  2. 鍵盤で1音弾く → 判定(1): 鳴った / 無音
  3. コントローラーで **SELECT+→ を9回**押す → 1音弾く → 判定(2): 鳴った / 無音
  4. SELECT を離して **→ を1回**押す → 1音弾く → 判定(3): 鳴った / 無音
  5. **電源を入れ直す**。今度は **SELECT+→ を8回**押す → 1音弾く(鳴るはず)
  6. SELECT を離して、**→ を1回押す → 1音弾く**を繰り返し、**無音になったら止めて**回数 k を数える(最大20回。20回で消えなければ「消えず」)

予想: (1) 鳴る、(2) 鳴る(PC89 = 音量最大)、(3) 無音(PC90)。k は「8回目の着地点」から PC90 までの距離です。
