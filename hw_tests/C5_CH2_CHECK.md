# C5 追加: ch2 の電源ONを戻して、もう一度確認

原因: アプリが2つ同時に動いていて、microKEY2 の演奏が ch1 にも送られていました。また、ch2 の「電源を入れたときの音色」が **無音(マクロ20)のまま**になっています(A2 の書き込みが実行されていなかった)。
アプリは同時に1つしか起動できないように直しました。**A で書き込みがあります**(ch2 の電源ONを「音量最大(マクロ19)」に戻す)。

準備: 開いているアプリをすべて閉じる → ファミコンの電源を入れ直す → `run.bat`

| # | 手順 | 判定 |
|---|---|---|
| 0 | `run.bat` をもう一度ダブルクリック(2つ目を起動しようとする) | 「すでに起動しています」と出て、2つ目は開かなかった → はい/いいえ |
| A | 「★ カートリッジ」→「詳細な管理…」→「内部の対応表」→「記録済みのマクロを割り当てる」でマクロ「19」、PC「(しない)」、電源ON「2」→ 割り当てる → **電源を入れ直す** | 「完了しました」が出た → はい/いいえ |
| B | 「2 パルス波2」タブで、**画面の鍵盤**の C4 を押す | 鳴った → はい/いいえ |
| C | 2 パルス波2 のまま microKEY2 で弾き、送信ログを見る | 「ch2 ノートON … [スルー]」だけが出て、「ch1 ノートON … [スルー]」が出ない → はい/いいえ |
