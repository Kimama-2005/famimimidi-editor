# 段階1(土台)アプリの実機確認

この版は**カートリッジに何も書き込みません**(CC#45/50/51・SysEx は送信前に遮断され、ログに「遮断」と出ます)。
判定はすべて二択です。結果は一番下のテンプレートで報告してください。

準備:
- **Domino と Cubase を閉じる**(同じ MIDI ポートを取り合うため)
- KROSS2 → USB-MIDI の IN、USB-MIDI の OUT → ふぁみみみっでぃ、の接続はいつもどおり
- KROSS2 は ch1 で送信
- ファミコンの電源を入れ直しておく

---

## A. 起動
1. フォルダ内の `run.bat` をダブルクリック
- 判定: 「ふぁみみみっでぃ 音色エディタ(段階1)」の画面が出た → はい / いいえ
  (いいえ の場合は、黒い画面に出たメッセージを報告してください)

## B. 接続
1. 出力 = `USB MIDI Interface`、入力 = `USB MIDI Interface` を選ぶ
2. 「接続」を押す
- 判定: 右側の表示が緑色で「出力: USB MIDI Interface / 入力: USB MIDI Interface」になった → はい / いいえ
  (エラーが出た場合はその文面を報告してください)

## C. MIDIスルー(ON)
1. 「MIDIスルー」にチェックが入っていることを確認
2. KROSS2 で1音弾く
- 判定: 鳴った → はい / いいえ
- 下の送信ログに `OUT  90 ...  ch1 ノートON ...  [スルー]` の行が出ていれば正常です

## D. MIDIスルー(OFF)
1. 「MIDIスルー」のチェックを外す
2. KROSS2 で1音弾く
- 判定: **鳴らなかった** → はい / いいえ
- ログには `IN` の行が出ます(キーボードの信号は届いているが、流していない、という意味)
3. 終わったらチェックを戻す

## E. 音量(CC#7)の送信
1. 「ch1 パルス波1」タブの **CC#7 ボリューム** のスライダーを左端(0)まで動かす
2. KROSS2 で1音弾く
- 判定(1): **無音** → はい / いいえ
3. スライダーを右端(127)に戻して、1音弾く
- 判定(2): 鳴った → はい / いいえ

## F. サスティン・レベル(CC#79)の送信
1. **CC#79 サスティン・レベル** を「0」、**CC#75 ディケイ・タイム** のスライダーを 0 にする
2. KROSS2 で1音を**3秒長押し**する
- 判定(1): 押し続けているのに**音がすぐ消えた** → はい / いいえ
3. 「既定値に戻して送る」を押して、もう一度3秒長押しする
- 判定(2): 押している間**鳴り続けた** → はい / いいえ

## G. パニックボタン
1. KROSS2 で1音を押したままにする
2. 押したまま、画面右上の「パニック(全音停止)」をマウスで押す
- 判定: 鍵盤を押したままなのに**音が止まった** → はい / いいえ

## H. ログファイル
1. 「ログフォルダを開く」を押す
- 判定: 今日の日付の `.log` ファイルがあり、開くと画面と同じ内容が書かれている → はい / いいえ
